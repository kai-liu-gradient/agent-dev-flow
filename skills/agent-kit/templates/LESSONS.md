# Lessons from merged work

What work in this repository got wrong, kept so the next session does not
repeat it. Read this before changing code.

Each lesson is one rule, then why, then the evidence:

```
**<the rule, one sentence>**
- Why: <what went wrong when it was not followed>
- Evidence: <PR or commit that caused it> -> <PR or commit that fixed it>
- Seen: N× (<dates>)
```

"Seen" counts separate days a review found the same mistake. A lesson seen on
3 or more days moves into AGENTS.md or docs/agents/workflow.md as a standing
rule, and is listed below under "Moved" with where it went.

The nightly review (docs/agents/loops.md, loop 3) reads every merge after the
`reviewed-through` commit above, adds or updates lessons, and moves the
marker.
